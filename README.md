# Infrastructure Learning Lab

Personal lab untuk belajar dan bereksperimen dengan teknologi infrastructure, Linux, networking, virtualization, automation, dan container.

## Tujuan

- Belajar Linux System Administration
- Membangun homelab menggunakan KVM/libvirt
- Eksperimen jaringan virtual
- Belajar SSH, Docker, Terraform, Ansible
- Simulasi VPS sebelum deploy ke server nyata

## Struktur

```
automation/   Infrastructure automation
container/    Docker dan container runtime
docs/         Dokumentasi pembelajaran
images/       Image VM dan disk
iso/          Installer ISO
network/      Konfigurasi layanan jaringan
vm/           Virtual machine dan libvirt
```
