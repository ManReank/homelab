Cloud-init Templates

Direktori ini menyimpan template Cloud-init yang dapat digunakan kembali untuk beberapa jenis VM.

Template berisi konfigurasi umum yang tidak bergantung pada instance tertentu.

Konfigurasi instance-specific berada di:

vm/cloud-init/instances/

Seed ISO dihasilkan dari kombinasi konfigurasi Cloud-init dan digunakan saat provisioning VM.
